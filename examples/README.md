# Zap template notes

Zapier Zap templates are authored in the developer dashboard, not committed as
JSON. This directory holds the plain-text angle notes for the templates to build
during App Directory submission (Pass 3 in `../ROADMAP.md`):

- Sheets or database row to Generate Invoice, then email or store the result.
- New file to Validate Invoice, then branch a workflow on the `valid` result.
- Webhook to Convert Invoice, then upload the converted document.
